Privacy Policy

Audio Player application

This Privacy Policy applies to the Audio Player Android application (com.audioplayer.ahmd), which displays and plays the audio files stored on the user's device.

Information We Collect

The application does not collect, store, or transmit any personal information or usage data. No information is sent to the developer or to any third party.

Handling of Audio Files

The application reads audio file metadata (title, artist, album, duration, and artwork) from the device solely in order to display and search the user's library. This processing takes place locally and temporarily within the application's memory.

When an audio file is opened from another application, it is played directly without being copied or uploaded.

Permissions

  • READ_MEDIA_AUDIO — Android 13 (API 33) and later: required to display and play audio files on the device.
  • READ_EXTERNAL_STORAGE — Android 12 (API 32) and earlier: required for the same purpose.
  • POST_NOTIFICATIONS — Android 13 and later: used to display the playback notification and controls. This permission is optional, and the application functions without it.
  • FOREGROUND_SERVICE and FOREGROUND_SERVICE_MEDIA_PLAYBACK — used to continue playback while the screen is locked or another application is in use.

The application does not request access to the internet, camera, microphone, location, or contacts.

Third-Party Libraries

The application is built with open-source libraries (AndroidX Media3 and Coil) that operate entirely on the device and do not transmit any data. The application contains no advertising, analytics, or tracking services.

Sharing the Application

The share feature opens the system share sheet in order to send a link to the application only. The application does not access the user's contacts or messages.

Children's Privacy

The application does not collect data from any user, including children.

User Control and Data Deletion

As no data is retained by the developer, there is nothing to delete. Users may revoke any permission at any time through Device Settings → Apps → Audio Player → Permissions. Uninstalling the application removes all of its data from the device.

Google Play Data Safety

  • Data collected: None.
  • Data shared with third parties: None.
  • Advertising: None.

Changes to This Policy

This policy may be updated when new features are introduced. The most recent version will be published on this page together with the date of the update.
